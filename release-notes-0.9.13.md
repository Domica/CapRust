## Added

- **Text effects parity.** EFFECTS stack now renders on text/caption overlays.
- **Blend modes.** Per-clip compositing (multiply, screen, overlay, darken, lighten, difference, …).
- **Clip rename.** Double-click or context menu; modal, undoable.
- **Refresh imported files.** Re-checks every library path; toast report.
- **Per-clip split display.** Strip on top, waveform band at bottom; global default in Settings.
- **Clip border width + color.** Thickness slider and fixed-color override.

### Changed

- **Logs + update checks moved to About.** Bottom of Settings → About tab.

- `CapRust-0.9.13-win64-setup.exe` — signed Inno Setup installer
- `caprust-nightly-linux.zip` — Linux nightly binary archive

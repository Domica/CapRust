Built for short-form creators

Everything you need for TikTok, Reels and Shorts — nothing you don't.

⚡

Native and fast

A single binary built with Rust and egui. Starts in under half a second, uses a fraction of the RAM of an Electron editor.

🎙

AI captions, on device

Whisper generates captions locally. Word-level timings drive a karaoke-style progressive reveal. No audio leaves your machine.

🎯

Auto-reframe

SCRFD face detection follows the speaker and keeps them centred when you switch from landscape to 9:16.

✂️

Magnetic timeline

Ripple delete, snap, trim-follow playhead, multi-select drag, transitions with xfade. It just works.

🎚

Audio that behaves

Fade handles on the waveform, volume keyframes, auto-ducking against music, segmented speed ramps with synced audio.

📹

Screen recording

Record a monitor straight into the media bin. Native DXGI Desktop Duplication, cursor overlay, no OBS or virtual device.

🎬

Multi-camera

Group 2+ clips as camera angles, switch between them from a dock panel, and auto-sync the audio via envelope correlation.

🚀

Hardware encoding

NVENC and AMF on top of the CPU path. Probed at runtime; the export dialog offers only encoders that open on this machine.

🧩

CLAP plugin hosting

Load your favourite CLAP plugins on the master bus. Verified with u-he ZebraHZ 2.9.4.

🤖

MCP server

Drive the editor from Claude Desktop, Cursor, or your own phone through a Model Context Protocol server. 27 tools, undo-stack integrated. Off by default; one checkbox opens it to your local network.

🟩

Chroma key

Green screen in one click. Per-clip key colour, similarity, and edge blend. Preview and export share the same filtergraph.

🎨

Stickers

108 bundled PNGs in 8 categories. Drag one onto the frame to place it, size it, turn it, or give it one of four animations. The preview draws them, so it is instant and does not depend on the preview quality.

🕒

Keyframed movement

A Trajectory tab for text and for stickers: mark where the thing is at which moment and it moves there. Move it on the frame and the keyframe under the playhead follows.

☁️

Settings that travel

Point CapRust at a Drive, OneDrive or Dropbox folder and it keeps settings in step across machines.

🔌

Plugin system

CLAP plugins on the master bus, importers discovered from a JSON manifest, and a JSON-RPC bridge. Drop a plugin in a scan folder and it shows up, no reinstall.

📐

Layout modes

Two editors, one project. Default is the dock — every panel is a tab you can drag anywhere. Modern is fixed — six zones, nothing to rearrange.

🗂

Tab layouts

Media bin with or without the filter sidebar, and a Modern layout where each zone picks its panel from a dropdown instead of holding whatever was dragged there.

Frequently asked

Is it free?
Yes. CapRust is MIT-licensed open source. No account, no telemetry, no upsell. The source is on GitHub.
Why only Windows?
Windows is the primary target — the majority of short-form creators ship from Windows machines. The core crate is written to be portable and it compiles on Linux and macOS in CI, but UX polish (native dialogs, taskbar integration, WASAPI) is Windows-only.
Where is FFmpeg?
CapRust does not link FFmpeg — it calls ffmpeg.exe and ffprobe.exe as subprocesses. On first run, if neither is on your PATH, it offers to download a static BtbN build (~110 MB) into %APPDATA%\CapRust\ffmpeg.
Do I need to download AI models?
Only if you want auto-captions, narration, auto-reframe or background removal. They download on demand from Settings → AI Models and live in %APPDATA%\CapRust\models. The editor works without them.
It says "beta" — is it stable?
v0.9.23 brings the editor to Android and auto-updates; v0.9.20 added a first-run welcome, guided tips and the Enhance effect; v0.9.19 added stickers and keyframed movement; v0.9.18 added the Modern editor, plugin-based importers and remote control. Everything from 0.9.0 onwards is included: chroma key, multicam, screen recording, and the original envelope overlay. The rest of the editor - timeline, preview, export, captions, audio effects, CLAP hosting and the MCP server are all in. Expect rough edges; a crash handler writes a report to %APPDATA%\CapRust\crashes if anything goes wrong, and the log is worth attaching to a GitHub issue.
Can I control CapRust from my phone?
Yes — and the phone is not the point. CapRust listens on a TCP socket speaking the same Model Context Protocol it already serves to Claude Desktop and Cursor: 27 tools, the same undo stack, the session that is open right now. Off by default, and bound to loopback only until you ask for more.

Ticking Settings → Paths → Allow remote control starts it. Ticking Allow devices on this network as well puts it on your LAN, and that is the point where a six-digit pairing code becomes required: valid five minutes, one try only, exchanged for a stored token you can revoke.

An Android app that speaks this protocol is built in CI and shipped through nightly builds. It is not part of this release and has not yet had a full pass on a device, so treat it as a preview. Any other MCP client speaks to the same socket — nothing about remote control depends on the phone app existing.
Windows SmartScreen warns me. Is that normal?
Yes. The beta is not code-signed yet. Click More info → Run anyway. Code signing is planned before the stable release.

Frequently asked

Is it free?
Yes. CapRust is MIT-licensed open source. No account, no telemetry, no upsell. The source is on GitHub.
Why only Windows?
Windows is the primary target — the majority of short-form creators ship from Windows machines. The core crate is written to be portable and it compiles on Linux and macOS in CI, but UX polish (native dialogs, taskbar integration, WASAPI) is Windows-only.
Where is FFmpeg?
CapRust does not link FFmpeg — it calls ffmpeg.exe and ffprobe.exe as subprocesses. On first run, if neither is on your PATH, it offers to download a static BtbN build (~110 MB) into %APPDATA%\CapRust\ffmpeg.
Do I need to download AI models?
Only if you want auto-captions, narration, auto-reframe or background removal. They download on demand from Settings → AI Models and live in %APPDATA%\CapRust\models. The editor works without them.
It says "beta" — is it stable?
v0.9.6 adds disabled widget states and error toasts for save, load, export, undo and redo. Everything from 0.9.0 through 0.9.5 is included: chroma key, multicam, screen recording, and the original envelope overlay. The rest of the editor - timeline, preview, export, captions, audio effects, CLAP hosting and the MCP server are all in. Expect rough edges; a crash handler writes a report to %APPDATA%\CapRust\crashes if anything goes wrong, and the log is worth attaching to a GitHub issue.
Windows SmartScreen warns me. Is that normal?
Yes. The beta is not code-signed yet. Click More info → Run anyway. Code signing is planned before the stable release.
